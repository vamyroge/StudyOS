# STUDYOS — UI / UX SYSTEM

## 1. DESIGN DIRECTION

StudyOS should feel like a modern productivity SaaS rather than a generic AI chatbot.

Design references:

```text
Linear
Vercel
Notion
modern educational SaaS
```

---

# 2. PRINCIPLES

```text
Clean
Fast
Information-dense
Focused
Responsive
Accessible
Consistent
```

---

# 3. UI LIBRARY

Prefer:

```text
shadcn/ui
Tailwind CSS
existing project primitives
```

Do not create custom versions of existing primitives unnecessarily.

---

# 4. CORE STATES

Every important interface should account for:

```text
loading
success
empty
error
disabled
permission denied
offline / provider unavailable
```

---

# 5. AI INTERFACE

The AI experience should support:

```text
conversation
sources
hints
steps
follow-up
retry
feedback
learning action
```

Do not make every screen look like a chat interface.

---

# 6. DASHBOARD

Prioritize actionable information:

```text
What should I do?
Why?
What is weak?
What improved?
What is next?
```

---

# 7. RESPONSIVENESS

Support:

```text
desktop
tablet
mobile
```

Do not assume desktop-only layouts.

---

# 8. ACCESSIBILITY

Use:

```text
semantic HTML
keyboard navigation
visible focus
appropriate labels
readable contrast
```
