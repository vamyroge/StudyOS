Làm trực tiếp trong project StudyOS hiện tại. Đọc và hiểu toàn bộ auth flow hiện tại trước khi sửa code.

MỤC TIÊU:
Xây dựng flow xác minh email hoàn chỉnh, chuyên nghiệp và production-ready cho StudyOS bằng Supabase Auth.

THÔNG TIN PROJECT:
- Brand: StudyOS
- Local: http://localhost:3000
- Production: https://tryeustudyhub.vercel.app/
- Auth provider: Supabase Auth
- Sau khi xác minh: user được đưa tới /verify-email và phải tự bấm "Tiếp tục" để vào /dashboard.

FLOW BẮT BUỘC:

1. User vào /signup.
2. User nhập form đăng ký hiện tại của StudyOS.
3. StudyOS gọi Supabase signUp().
4. Supabase tạo account.
5. Nếu email confirmation đang bật:
   → KHÔNG đưa user vào dashboard.
   → chuyển tới /verify-email hoặc trạng thái chờ xác minh phù hợp.
6. Supabase gửi email xác minh.

- Cooldown 60 giây

- Cho phép bấm "Tiếp tục"

AUTH LOGIC:

Trước khi code, hãy tìm và kiểm tra:
- signup page/component
- login
- Supabase browser client
- Supabase server client
- middleware/proxy
- auth callback hiện tại
- dashboard protection
- existing auth hooks/context
- existing environment variables
- existing email/auth configuration logic

Nếu đã có callback:
- sửa/tái sử dụng callback hiện tại
- KHÔNG tạo duplicate callback.

Nếu chưa có callback:
- tạo callback đúng với kiến trúc Next.js hiện tại.

Đảm bảo không tạo:
- redirect loop
- duplicate session
- duplicate auth listener
- race condition
- dashboard access trước khi verification nếu confirmation đang bật.
