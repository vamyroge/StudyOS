# StudyOS - Project Context

## Product
StudyOS is an AI Study Platform for Vietnamese high school students (THPT).

## MVP Subjects
- Math (Toán)
- Physics (Vật lý)  
- Chemistry (Hóa học)

Architecture must be extensible to other subjects without rewriting core.

## Curriculum
- GDPT 2018 (Vietnamese national curriculum)
- Supports multiple textbook series
- No hard-coding to a single textbook

## Roles
- STUDENT: primary user
- ADMIN: system management, moderation, content, research

No TEACHER role in MVP.

## Core Research Direction
Student Model + Knowledge Base + Knowledge Graph + Knowledge Tracing + Adaptive Learning + Evidence-based RAG + Learning Analytics

LLM is one component, not the entire product.

## Product Goals
Students can: learn, ask AI, solve problems, practice, analyze errors, track progress, discover weaknesses, get personalized recommendations, review, build mastery per concept.

## Research Goals
System must support: Knowledge Base, Knowledge Graph, Student Model, Knowledge Tracing, Error/Misconception Analysis, Adaptive Learning, Evidence-based RAG, Learning Analytics, AI Model Evaluation, Educational Experimentation.

## Status
- Phase 0: COMPLETE (environment setup)
- Phase 1: IN PROGRESS (product foundation)
